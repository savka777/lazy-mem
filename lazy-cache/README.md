# Lazy Cache

This folder is reserved for future generated Lazy Mem support files.

Possible generated artifacts:

- `index.json`
- `index.sqlite`
- `backlinks.json`
- `routes.json`
- `broken-links.json`

These files are helpers, not durable memory. The source of truth is the markdown memory repo plus git history.
Cache contents should be safe to delete and rebuild.
