> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Lazy Mem V0 central markdown memory scaffold, universal harness instructions, project pointer templates, and `lazy-mem attach` helper.

**Architecture:** Lazy Mem V0 is a filesystem-native markdown repo. The central repo contains human-readable memory files and templates; projects opt in by receiving a plain YAML `.lazy-mem` pointer generated by `bin/lazy-mem attach`.

**Tech Stack:** POSIX shell, markdown, YAML-like text files, git, `find`, `grep`, `mktemp`, and standard macOS/Linux command-line tools.

````md
# Lazy Mem

Lazy Mem is a central markdown memory repo for agent harnesses.

The V0 idea is simple:

1. Keep durable memory in this folder.
2. Attach any project with a `.lazy-mem` pointer file.
3. Teach any agent to read `.lazy-mem`, then `SYSTEM.md`.
4. Route to the smallest useful memory files instead of preloading everything.
5. Write memory updates as proposals unless the user explicitly asks for direct edits.

## Quick Start

From inside any project:

```bash
/path/to/lazy-mem/bin/lazy-mem attach .
```

Then tell an agent:

```text
Use Lazy Mem.
```

The agent should read the project's `.lazy-mem` pointer, load this repo's `SYSTEM.md`, and follow the routing rules.

## Core Contract

Lazy Mem works with any harness that can read files:

```text
If a project has a .lazy-mem pointer file, read it first.
Then read the central Lazy Mem SYSTEM.md it points to.
Do not preload the whole memory repo.
```
````

- [ ] **Step 2: Create `SYSTEM.md`**

````md
# Lazy Mem System Instructions

You are using Lazy Mem as external memory.

## Universal Harness Contract

If a project has a .lazy-mem pointer file, read it first.
Then read the central Lazy Mem SYSTEM.md it points to.
Follow SYSTEM.md before deciding what memory to load.
Do not preload the whole memory repo.

## How To Use Lazy Mem

1. Read the project's `.lazy-mem` file as YAML.
2. Resolve `memory_repo`.
3. Resolve `system_file`; this is usually `SYSTEM.md`.
4. Read `ROUTERS.md`.
5. Use `project_id` to find the matching `projects/<project_id>.md` page.
6. Read only the project, procedure, person, state, or source files needed for the task.
7. Stop reading when enough context exists.
8. If the task meaningfully used Lazy Mem, write or propose a read trace under `logs/read-traces/`.

## Write Policy

Do not directly edit durable memory by default.

For meaningful memory updates, create a proposal under `proposals/pending/` that includes:

- affected files
- reason for the change
- source evidence
- confidence
- exact replacement or append text

Direct edits are allowed only for append-only logs, low-risk traces, or when the user explicitly asks for direct memory updates.

## Read Path Explanation

When useful, explain:

- which Lazy Mem files you opened
- why you opened each file
- why you stopped reading
- whether you found enough context

## Conflict Policy

If memory files conflict, prefer higher `authority`, then newer `freshness`.
If the conflict matters, surface it instead of silently merging it.
````

````md
# Lazy Mem Rules

## Durable Memory

Do not directly edit durable memory by default.

Durable memory includes:

- `projects/`
- `people/`
- `procedures/`
- committed source summaries

Use proposals for meaningful changes.

## Temporary State

State files are working memory, not durable truth.
Do not promote state into durable memory without a proposal or explicit user request.

## Sources

Do not rewrite raw sources.
Use `sources/` for references, imports, and evidence.

## Secrets

Never store API keys, passwords, private tokens, or credentials in Lazy Mem.
Reject memory proposals that contain secrets.

## Authority

When files conflict:

1. Prefer higher `authority`.
2. Prefer newer `freshness` when authority is equal.
3. Surface unresolved contradictions.

## Traces

Read traces and write traces should be append-only records of what happened.
````

**Files:**

- [ ] **Step 1: Create `bin/lazy-mem`**

```sh
#!/usr/bin/env sh
set -eu

SELF="$0"
BIN_DIR="$(cd "$(dirname "$SELF")" && pwd)"
MEMORY_REPO="$(cd "$BIN_DIR/.." && pwd)"

usage() {
  cat <<'USAGE'
Usage:
  lazy-mem attach [project_path] [--id project-id]
  lazy-mem help

Commands:
  attach   Create a .lazy-mem pointer inside a project.
  help     Show this help.
USAGE
}

slugify() {
  printf '%s' "$1" |
    tr '[:upper:]' '[:lower:]' |
    sed 's/[^a-z0-9][^a-z0-9]*/-/g; s/^-//; s/-$//'
}

project_title() {
  base="$(basename "$1")"
  printf '%s' "$base" | sed 's/-/ /g; s/_/ /g'
}

write_pointer() {
  project_path="$1"
  project_id="$2"
  pointer_path="$project_path/.lazy-mem"

  cat > "$pointer_path" <<EOF
memory_repo: $MEMORY_REPO
project_id: $project_id
system_file: SYSTEM.md
EOF
}

create_project_page_if_missing() {
  project_path="$1"
  project_id="$2"
  title="$3"
  today="$(date +%Y-%m-%d)"
  page="$MEMORY_REPO/projects/$project_id.md"

  if [ -f "$page" ]; then
    return 0
  fi

  mkdir -p "$MEMORY_REPO/projects"

  sed \
    -e "s/__PROJECT_ID__/$project_id/g" \
    -e "s/__PROJECT_TITLE__/$title/g" \
    -e "s#__PROJECT_PATH__#$project_path#g" \
    -e "s/__DATE__/$today/g" \
    "$MEMORY_REPO/templates/project.md" > "$page"
}

cmd_attach() {
  target="."
  project_id=""

  while [ "$#" -gt 0 ]; do
    case "$1" in
      --id)
        shift
        if [ "$#" -eq 0 ]; then
          echo "missing value for --id" >&2
          exit 2
        fi
        project_id="$1"
        ;;
      -*)
        echo "unknown option: $1" >&2
        exit 2
        ;;
      *)
        target="$1"
        ;;
    esac
    shift
  done

  mkdir -p "$target"
  project_path="$(cd "$target" && pwd)"

  if [ -z "$project_id" ]; then
    project_id="$(slugify "$(basename "$project_path")")"
  fi

  if [ -z "$project_id" ]; then
    echo "could not determine project id" >&2
    exit 2
  fi

  title="$(project_title "$project_path")"

  write_pointer "$project_path" "$project_id"
  create_project_page_if_missing "$project_path" "$project_id" "$title"

  echo "Attached Lazy Mem to $project_path"
  echo "Project id: $project_id"
```
